# CyberSmrt K-12 Cybersecurity Curriculum Structure

## Overview

The CyberSmrt K-12 Cybersecurity Curriculum is a comprehensive, competency-based program designed to take students from digital literacy fundamentals in 5th grade through professional-level cybersecurity specialization by high school graduation. The curriculum is structured to provide students with industry-recognized certifications, real-world experience, and professional portfolios that position them for immediate career entry or advanced education.

## Curriculum Philosophy

- **Progressive Complexity**: Each grade builds on previous knowledge
- **Industry Alignment**: Curriculum maps to industry certifications (CompTIA, ISC2)
- **Hands-On Learning**: Practical labs and real-world scenarios
- **Career Pathways**: Clear specialization tracks in high school
- **Professional Development**: Portfolio building, resume development, and work experience documentation
- **CISSP Pathway**: High school curriculum designed to fulfill ISC2 CISSP 5-year work experience requirement

## Elementary Foundation

### Grade 5: Digital Fluency & Cyber Hygiene
**Program Type**: Foundation
**Prerequisites**: None
**Duration**: Full academic year

#### Learning Objectives
- Understand basic internet safety principles
- Recognize common online threats (phishing, scams, inappropriate content)
- Create and manage strong passwords
- Practice digital citizenship and online etiquette
- Understand personal data privacy

#### Key Topics
1. **Internet Safety Basics**
   - Safe browsing habits
   - Identifying trusted vs. untrusted websites
   - Understanding website security indicators (HTTPS, lock icons)

2. **Password Security**
   - What makes a strong password
   - Password managers introduction
   - Never sharing credentials

3. **Recognizing Threats**
   - Phishing emails and messages
   - Too-good-to-be-true offers
   - Suspicious links and attachments
   - Stranger danger online

4. **Digital Citizenship**
   - Respectful online communication
   - Cyberbullying awareness and prevention
   - Digital footprint concept
   - Responsible social media use (age-appropriate)

5. **Privacy Fundamentals**
   - What is personal information
   - Why privacy matters
   - Permission and consent online
   - Family discussions about sharing

#### Hands-On Activities
- Password strength tester tool usage
- Phishing email identification exercises
- Safe/unsafe website sorting games
- Digital citizenship scenarios

#### Assessment
- Interactive quizzes
- Scenario-based problem solving
- Parent/family engagement activities
- End-of-year cybersecurity awareness certificate

#### Tools & Resources
- CyberSmrt Password Checker tool
- CyberSmrt Phishing Detector tool
- Age-appropriate cybersecurity games
- Family discussion guides

## Middle School Progression

### Grade 6: IT Basics
**Program Type**: Technical Foundation
**Prerequisites**: Grade 5 or equivalent digital literacy
**Duration**: Full academic year

#### Learning Objectives
- Understand computer hardware components and functions
- Navigate operating systems (Windows, macOS, Linux basics)
- Understand basic networking concepts
- Use productivity tools effectively
- Perform basic troubleshooting

#### Key Topics
1. **Computer Hardware**
   - CPU, RAM, storage devices
   - Input/output devices
   - Motherboards and components
   - Assembly basics (virtual or physical)

2. **Operating Systems**
   - Windows environment
   - macOS basics
   - Linux introduction (command line basics)
   - File systems and organization

3. **Networking Fundamentals**
   - What is a network?
   - IP addresses (basic concept)
   - Internet vs. intranet
   - Wi-Fi and wired connections

4. **Digital Tools**
   - Word processing
   - Spreadsheets basics
   - Presentations
   - Collaboration tools

5. **Basic Troubleshooting**
   - Problem identification
   - Restarting and basic fixes
   - When to ask for help
   - Safe troubleshooting practices

#### Hands-On Labs
- Virtual PC building/assembly
- Operating system navigation challenges
- Network cable creation (Cat5/Cat6)
- Software installation and updates

#### Assessment
- Hardware identification quizzes
- OS navigation practical exams
- Troubleshooting scenarios
- Digital portfolio creation

**Program Type**: Technical Advanced
**Prerequisites**: Grade 6 IT Basics or equivalent
**Duration**: Full academic year
**Certification Prep**: CompTIA A+, Network+, Security+ (Foundational)

#### Learning Objectives
- Master hardware troubleshooting and repair
- Configure and manage network infrastructure
- Understand security fundamentals
- Prepare for industry certifications
- Develop technical documentation skills

#### Key Topics

**CompTIA A+ Fundamentals**
1. **Hardware**
   - PC components in depth
   - Mobile device hardware
   - Printers and peripherals
   - Hardware troubleshooting methodology

2. **Operating Systems**
   - Windows installation and configuration
   - macOS and Linux administration basics
   - Command line operations
   - Troubleshooting OS issues

**CompTIA Network+ Basics**
3. **Networking Infrastructure**
   - OSI Model layers
   - TCP/IP fundamentals
   - Network devices (routers, switches, access points)
   - IPv4 and IPv6 addressing
   - Subnet basics

4. **Network Operations**
   - Setting up home/small office networks
   - Wi-Fi configuration and security
   - Network troubleshooting tools (ping, ipconfig, etc.)

**CompTIA Security+ Introduction**
5. **Security Concepts**
   - Confidentiality, Integrity, Availability (CIA Triad)
   - Authentication and authorization
   - Encryption basics
   - Threat landscape overview

6. **Security Best Practices**
   - Securing workstations
   - Network security basics
   - Data backup and recovery
   - Password policies

#### Hands-On Labs
- Computer repair and upgrade projects
- Home network setup and configuration
- Virtual machine deployment
- Basic penetration testing introduction (Kali Linux basics)
- Security configuration exercises

#### Certification Pathway
- Students can optionally pursue CompTIA ITF+ or A+ certification
- Curriculum aligns with certification objectives
- Practice exams and study materials provided

#### Assessment
- CompTIA-style practice exams
- Lab practicals
- Technical documentation projects
- Peer troubleshooting exercises

## High School Specialization

### Grade 9: Track Selection & Foundations
**Program Type**: Specialization Foundation
**Prerequisites**: Grade 8 General Cybersecurity or equivalent
**Duration**: Full academic year
**Track Selection**: Students choose one of three specialized paths

#### Track Selection Process
- **Career Interest Survey**: Students complete aptitude and interest assessment
- **Track Overview Sessions**: Introduction to each specialization
- **Guest Speakers**: Professionals from each field
- **Trial Period**: First month allows track exploration before committing
- **Parent/Guardian Consultation**: Family involvement in decision

## 🔴 Red Team Track (Offensive Security)

### Grade 9: Red Team Foundations
#### Learning Objectives
- Understand ethical hacking principles and legal boundaries
- Learn reconnaissance and information gathering
- Master scanning and enumeration techniques
- Develop basic exploitation skills
- Document findings professionally

#### Key Topics
1. **Ethical Hacking Framework**
   - Laws and regulations (CFAA, ethical boundaries)
   - Rules of engagement
   - Scope and authorization
   - Professional conduct

2. **Reconnaissance**
   - Open-source intelligence (OSINT)
   - Passive vs. active reconnaissance
   - Social engineering basics
   - Information gathering tools

3. **Scanning & Enumeration**
   - Port scanning (Nmap)
   - Service enumeration
   - Vulnerability scanning (Nessus, OpenVAS)
   - Network mapping

4. **Exploitation Basics**
   - Common vulnerabilities (OWASP Top 10)
   - Metasploit introduction
   - Basic exploit development concepts
   - Post-exploitation fundamentals

5. **Reporting**
   - Technical writing for security
   - Proof of concept documentation
   - Risk rating and prioritization
   - Remediation recommendations

#### Tools & Platforms
- Kali Linux
- Metasploit Framework
- Burp Suite
- Nmap
- CloudRange (for safe practice environments)

### Grades 10-12: Red Team Advanced
#### Progressive Topics
- **Grade 10**: Web application pentesting, API security, wireless attacks
- **Grade 11**: Advanced exploitation, privilege escalation, Active Directory attacks
- **Grade 12**: Red team operations, assumed breach scenarios, adversary simulation

#### Certifications Pathway
- **Grade 10**: CEH (Certified Ethical Hacker) preparation
- **Grade 11**: OSCP (Offensive Security Certified Professional) - Junior level
- **Grade 12**: GPEN (GIAC Penetration Tester) or similar

## 🔵 Blue Team Track (Defensive Security)

### Grade 9: Blue Team Foundations
#### Learning Objectives
- Understand defensive security operations
- Learn threat detection and analysis
- Master incident response fundamentals
- Develop monitoring and analysis skills
- Build defensive strategies

#### Key Topics
1. **Defensive Security Operations**
   - Defense-in-depth concept
   - Security monitoring lifecycle
   - Threat intelligence basics
   - SOC organization and roles

2. **Threat Detection**
   - Log analysis fundamentals
   - Signature vs. behavior-based detection
   - Indicators of Compromise (IOCs)
   - SIEM tools introduction

3. **Incident Response**
   - IR lifecycle (NIST framework)
   - Evidence collection and preservation
   - Containment strategies
   - Eradication and recovery

4. **Security Monitoring**
   - Network traffic analysis
   - Endpoint detection and response (EDR)
   - Alert triage and investigation
   - False positive management

5. **Defensive Tools**
   - Firewalls and IDS/IPS
   - Antivirus and anti-malware
   - Security information event management (SIEM)
   - Forensics tools basics

#### Tools & Platforms
- Splunk / ELK Stack
- Wireshark
- Security Onion
- Snort / Suricata
- CloudRange (for defense simulations)

### Grades 10-12: Blue Team Advanced
#### Progressive Topics
- **Grade 10**: Malware analysis basics, digital forensics, threat hunting
- **Grade 11**: Advanced SIEM operations, automation and orchestration (SOAR), threat intelligence
- **Grade 12**: Advanced persistent threat (APT) defense, zero trust architecture, cloud security

#### Certifications Pathway
- **Grade 10**: CompTIA CySA+ (Cybersecurity Analyst)
- **Grade 11**: GCIH (GIAC Certified Incident Handler)
- **Grade 12**: GCFA (GIAC Certified Forensic Analyst) or GCIA (GIAC Certified Intrusion Analyst)

### Grade 9: GRC Foundations
#### Learning Objectives
- Understand governance frameworks and standards

#### Key Topics
1. **Governance Frameworks**

2. **Risk Management**
   - Risk identification and assessment

   - Compliance vs. security
   - Audit preparation
   - Documentation requirements

4. **Policy Development**
   - Security policy structure
   - Standards, procedures, and guidelines
   - Policy lifecycle management
   - Stakeholder communication

5. **Audit & Assessment**
   - Control testing
   - Evidence collection
   - Gap analysis
   - Remediation planning

#### Tools & Platforms
- GRC platforms (introductory)
- Risk assessment tools
- Policy management systems
- CloudRange (for risk scenarios)

### Grades 10-12: GRC Advanced
#### Progressive Topics
- **Grade 10**: Privacy compliance, third-party risk management, business continuity planning

## Cross-Cohort Collaborative Learning (Grades 10-12)

### Live Cyber Range Exercises (CloudRange Platform)

#### Exercise Structure
**Frequency**: Quarterly major exercises, monthly mini-exercises

#### Scenario-Based Learning
1. **Red Team Mission**
   - Given objectives and rules of engagement
   - Conduct reconnaissance on Blue Team infrastructure
   - Identify and exploit vulnerabilities
   - Maintain persistence and exfiltrate simulated data
   - Document all actions and findings

2. **Blue Team Mission**
   - Monitor and defend infrastructure in real-time
   - Detect Red Team activities
   - Respond to incidents as they occur
   - Contain and remediate compromises
   - Document incidents and lessons learned

3. **GRC Team Mission**
   - Conduct pre-exercise risk assessment
   - Work with Blue Team to review security controls
   - Observe exercise for compliance gaps
   - Assess policy effectiveness during incidents
   - Update policies and procedures based on findings
   - Present risk report to stakeholders (teachers/administrators)

#### Learning Outcomes
- **Cross-functional collaboration**: Understanding how security teams work together
- **Real-world pressure**: Decision-making under time constraints
- **Communication skills**: Technical and non-technical reporting
- **Continuous improvement**: Iterative learning from exercises

#### Documentation Requirements
- Red Team: Penetration test reports
- Blue Team: Incident reports and forensic analysis
- GRC Team: Risk assessments and policy updates

## CISSP Pathway (Grades 9-12)

### ISC2 Partnership Goal
**Objective**: Structure high school curriculum to fulfill the 5-year work experience requirement for CISSP certification

### CISSP Domain Mapping

#### Domain 1: Security and Risk Management
- **Primary Track**: GRC
- **Coverage**: Grades 9-12 GRC curriculum, all tracks cover in collaborative exercises
- **Experience Type**: Risk assessments, policy development, incident response planning

#### Domain 2: Asset Security
- **Primary Track**: Blue Team
- **Coverage**: Grades 9-10 (data classification, handling)
- **Experience Type**: Data protection strategies, DLP implementation

#### Domain 3: Security Architecture and Engineering
- **Primary Track**: All tracks
- **Coverage**: Grades 10-11 (security models, cryptography)
- **Experience Type**: Secure system design, architecture reviews (GRC), defense-in-depth (Blue)

#### Domain 4: Communication and Network Security
- **Primary Track**: Blue Team & Red Team
- **Coverage**: Grades 9-11
- **Experience Type**: Network monitoring (Blue), network attacks (Red), network policies (GRC)

#### Domain 5: Identity and Access Management
- **Primary Track**: All tracks
- **Coverage**: Grades 9-10
- **Experience Type**: IAM implementation (Blue), privilege escalation (Red), access policies (GRC)

#### Domain 6: Security Assessment and Testing
- **Primary Track**: Red Team & GRC
- **Coverage**: Grades 10-12
- **Experience Type**: Penetration testing (Red), audit and compliance testing (GRC)

#### Domain 7: Security Operations
- **Primary Track**: Blue Team
- **Coverage**: Grades 9-12
- **Experience Type**: SOC operations, incident response, monitoring, forensics

#### Domain 8: Software Development Security
- **Primary Track**: Red Team & Blue Team
- **Coverage**: Grades 11-12
- **Experience Type**: Secure coding (Blue), application pentesting (Red), SDLC policies (GRC)

### Experience Documentation
Students maintain a **CISSP Experience Portfolio** documenting:
- Projects completed in each domain
- Hours spent on relevant activities
- Collaborative exercises and roles
- Certifications achieved
- Skills and technologies used
- Supervisor/teacher endorsements

### Graduation Outcome
**Upon high school graduation at age 18:**
- Students have 4 years of documented cybersecurity experience
- Qualify as **CISSP Associate** (can sit for exam, 6-year timeframe to meet experience requirement)
- Final year of experience achieved through:
  - College cybersecurity internship, OR
  - Entry-level cybersecurity job, OR
  - Military cybersecurity role, OR
  - Continued volunteer work with CyberSmrt (documented)

## Assessment & Progression

### Competency-Based Advancement
Students advance based on **demonstrated mastery**, not seat time.

### Assessment Types
1. **Hands-On Labs** (40% of grade)
2. **Certification Practice Exams** (30% of grade)
3. **Projects and Portfolios** (20% of grade)
4. **Collaborative Exercises** (10% of grade)

### Progression Criteria
- **Pass**: 80%+ competency across all domains
- **High Pass**: 90%+ (eligible for advanced projects)
- **Mastery**: 95%+ (eligible to mentor younger students)
