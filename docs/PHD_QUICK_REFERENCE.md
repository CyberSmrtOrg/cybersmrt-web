# Ph.D. Research Partnership System - Quick Reference Card

## Daily Workflows

### ☀️ Monday Morning (30 minutes)
1. Open **"Action Required Today"** view
2. Update **Last Activity Date** for any weekend conversations
3. Plan this week's outreach priorities
4. Check **"Outcomes - Need Analysis"** → Schedule time to write analyses

### 📞 After Every Partnership Interaction (2 minutes)
1. Update **Last Activity Date** in Pipeline task
2. Increment **Total Touchpoints** counter
3. Update **Next Planned Action** and **Next Action Due Date**
4. Add comment with key quotes or insights

### ✅ When Partnership Outcome Occurs (5 minutes initial)
1. Update Pipeline task **Status** (✅ Secured / ❌ Declined / 🤷 Ghosted)
2. Automation creates Outcome Analysis task automatically
3. Schedule 30-60 min within next 48 hours to write full analysis

### 🌆 Wednesday Check-in (20 minutes)
1. Review **"Active Pipeline Overview"** board
2. Move stalled prospects to appropriate status
3. Update **Next Action Due Date** for active prospects
4. Review any new outcomes, create analysis tasks if automation didn't fire

### 🎉 Friday Wrap-up (45 minutes)
1. Conduct 1-2 pending **Outcome Analyses**
2. Update **Pitch Evolution Log** if you tested new messaging this week
3. Review **"Success Patterns"** and **"Rejection Patterns"** views
4. **Weekly Reflection:** What did I learn? What surprised me?
5. Plan next week's partnership priorities

## Core Views Cheat Sheet

| View Name | Purpose | When to Use |
|-----------|---------|-------------|
| **Active Pipeline Overview** | See all active prospects by stage | Every Monday/Wednesday |
| **High-Value Prospects** | Focus on $50K+ opportunities | Planning priorities |
| **Action Required Today** | What needs attention NOW | Every morning |
| **Warm Introductions Needed** | Track referral-based prospects | Before networking events |

| **Success Patterns** | Learn what's working | Monthly review |
| **Rejection Patterns** | Learn what's not working | Monthly review |

## Custom Fields Quick Reference

### Partnership Pipeline - Must Fill Fields
- ✅ **Organization Name**
- ✅ **Partnership Type**
- ✅ **Potential Value**
- ✅ **Strategic Fit Score** (1-Low to 4-Critical)
- ✅ **Next Action Due Date**
- ✅ **How We Found Them**

### Partnership Pipeline - Fill When Known
- **Primary Contact** + Contact Email/LinkedIn
- **Ask Amount** (if financial)
- **Decision Timeline** (when they'll decide)
- **Why We Chose Them** (strategic rationale)

### Outcomes Analysis - Critical Fields
- ✅ **Outcome** (Secured/Declined/Ghosted)
- ✅ **Why They Said Yes - Our Analysis** (if secured)
- ✅ **Suspected Real Reason** (if declined)
- ✅ **Key Learnings**
- ✅ **Application to Future Partnerships**

### Pitch Evolution - Track Per Version
- ✅ **Version Number** (v1.0, v2.0, etc.)
- ✅ **Times Used**
- ✅ **Meetings Secured**
- ✅ **Partnerships Secured**
- Calculate: **Success Rate** = Partnerships ÷ Times Used

## Status Flow Diagrams

### Partnership Pipeline Flow

```
Identified
    ↓
Outreach Planned
    ↓
Initial Contact
    ↓
Engaged ←→ (Can loop back to Engaged after meetings)
    ↓
Proposal Submitted
    ↓
Under Review
    ↓
    ├─→ ✅ Partnership Secured → Create Outcome Analysis
    ├─→ ❌ Declined → Create Outcome Analysis
    ├─→ 🤷 Ghosted → Create Outcome Analysis
    └─→ ⏸️ On Hold (can reactivate later)
```

### Outcome Analysis Flow

```
Needs Analysis (Auto-created from Pipeline)
    ↓
In Progress (You're writing the analysis)
    ↓
Complete (Analysis written, ready to extract insights)
    ↓
Synthesized (Insights integrated into pitch/strategy)
```

## Data Quality Checklist

Before moving a Partnership Pipeline task to final status, ensure:

- [ ] **Last Activity Date** is current
- [ ] **Total Touchpoints** is accurate
- [ ] **Final Outcome** dropdown is filled
- [ ] **Outcome Date** is set
- [ ] At least 2-3 sentence **Lessons Learned** is captured
- [ ] All email/document links are attached to task

Before marking an Outcome Analysis as "Complete", ensure:

- [ ] Narrative of what happened is clear
- [ ] Honest assessment of why (not just stated reason)
- [ ] Key learnings identified
- [ ] Future applications noted
- [ ] Any verbatim quotes captured
- [ ] Connected to broader patterns/themes

## Red Flags & Yellow Flags

### 🚩 Red Flags (Stop and Reflect)
- Last Activity > 21 days on "Engaged" prospect
- 3+ declined partnerships in a row
- Pitch success rate < 15% after 10+ uses
- Spending more time in ClickUp than talking to partners

### ⚠️ Yellow Flags (Pay Attention)
- Last Activity > 14 days on "Engaged" prospect
- "Ghosted" rate > 30% of all outcomes
- Not conducting outcome analyses within 1 week
- Only pursuing one type of partner (lack of diversity)

## Monthly Review Questions

On the last Friday of each month, spend 60-90 minutes reviewing:

1. **Pipeline Health**
   - How many active prospects?
   - What's the total potential value?
   - Which stages are moving vs. stuck?
   - Are we adding new prospects regularly?

2. **Success Patterns**
   - Which types of organizations are saying yes?
   - What pitch angles are resonating?
   - What's the average time to decision?
   - Are referrals working better than cold outreach?

3. **Failure Patterns**
   - Why are we getting declined?
   - Are objections consistent across sectors?
   - What red flags should we watch for earlier?
   - Do we need to adjust our target partner profile?

4. **Pitch Evolution**
   - Is our messaging getting more effective?
   - What changes improved performance?
   - What should we test next month?

5. **Research Insights**
   - What did I learn about nonprofit partnerships?
   - What surprised me about funder behavior?
   - What leadership skills am I developing?
   - What could contribute to academic literature?

## Quick Win: First 3 Tasks to Add

### Task 1: Current Top Prospect
- **List:** Partnership Pipeline
- **Status:** Wherever they currently are in your process
- **Fill:** Organization Name, Type, Potential Value, Strategic Fit, Next Action
- **Goal:** Get comfortable with the system

### Task 2: Recent Outcome (if you have one)
- **List:** Partnership Outcomes Analysis
- **Status:** Needs Analysis
- **Fill:** Organization Name, Outcome, Outcome Date
- **Goal:** Practice doing an analysis

### Task 3: Current Pitch Version
- **List:** Pitch Evolution Log
- **Status:** Active Version
- **Fill:** Version Number (v1.0), Target Audience, Times Used so far
- **Attach:** Your current deck or one-pager
- **Goal:** Baseline for measuring improvement

## When to Expand the System

Consider adding more lists/fields when:

- ✅ You're using the current system consistently for 2+ weeks
- ✅ You've logged 10+ partnership attempts
- ✅ You're finding value in the data you're capturing
- ✅ You've identified specific gaps in what you can track
- ✅ You have 15-20 min/day to maintain a more complex system

Don't expand if:
- ❌ You're not consistently using the current fields
- ❌ The system feels like a burden rather than a tool
- ❌ You're spending more time documenting than doing

---

## Remember

### The System Should:
- ✅ Make fundraising easier, not harder
- ✅ Provide insights that improve your approach
- ✅ Capture data for your dissertation
- ✅ Take < 20 min/day to maintain

### The System Should NOT:
- ❌ Slow down your partnership development
- ❌ Create busywork that doesn't add value
- ❌ Require perfection in data entry
- ❌ Become a procrastination tool

---

## Emergency Simplification

If the system feels overwhelming, simplify to these 3 actions only:

1. **After every interaction:** Update status + next action date (30 seconds)
2. **After every outcome:** Write 3-5 sentence analysis (5 minutes)
3. **Every Friday:** Review active pipeline, plan next week (15 minutes)

That's it. The rest is bonus.
