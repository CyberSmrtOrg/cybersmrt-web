# Setup Guide

## Prerequisites

- Python 3.9 or higher
- pip package manager
- Git
- An Anthropic API key ([get one here](https://console.anthropic.com/))

## Installation Steps

### 1. Add Agent to Your Repository

In your repository root:

```bash
# Create agent directory
mkdir -p agent
mkdir -p .github/workflows

# Copy all agent files to agent/ directory
# - indexer.py
# - query_engine.py
# - tools.py
# - cli.py
# - config.yml
# - requirements.txt

# Copy workflow file to .github/workflows/
# - update-index.yml
```

### 2. Install Python Dependencies

```bash
cd agent
pip install -r requirements.txt --break-system-packages
```

**Note:** The `--break-system-packages` flag is required on some systems. If it causes issues, create a virtual environment instead:

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Configure the Agent

Edit `agent/config.yml`:

```yaml
# Required: Your Anthropic API key
anthropic_api_key: "sk-ant-api03-..."

# Adjust if needed
repo_path: ".."  # Path to repo root from agent directory

# Customize ignore patterns for your project
ignore_patterns:
  - "node_modules"
  - "dist"
  - "build"
  - ".git"
  - "coverage"
  - ".next"
  - "public/assets"  # Add your own patterns

# Add any custom file extensions
file_extensions:
  - ".js"
  - ".jsx"
  - ".html"
  - ".ts"
  - ".tsx"
```

### 4. Index Your Codebase

```bash
python indexer.py
```

This will:
- Scan your repository for JS/HTML files
- Parse and analyze each file
- Create embeddings for semantic search
- Build dependency graphs
- Store everything in `agent_data/`

**Expected time:**
- Small repo (<100 files): 1-2 minutes
- Medium repo (100-500 files): 5-10 minutes
- Large repo (500+ files): 15-30 minutes

### 5. Test the Agent

```bash
# Interactive mode
python cli.py

# Or ask a single question
python cli.py "What does the main application entry point do?"
```

### 6. Set Up Auto-Indexing (Optional)

To automatically reindex when you push changes:

1. Add the GitHub Action workflow (already in `.github/workflows/update-index.yml`)

2. Add your Anthropic API key as a GitHub secret:
   - Go to your repo → Settings → Secrets and variables → Actions
   - Click "New repository secret"
   - Name: `ANTHROPIC_API_KEY`
   - Value: Your API key

3. Commit the workflow file:
   ```bash
   git add .github/workflows/update-index.yml
   git commit -m "Add auto-indexing workflow"
   git push
   ```

Now the index will update automatically when you push JS/HTML changes.

## Troubleshooting

### Import Errors

**Problem:** `ModuleNotFoundError: No module named 'anthropic'`

**Solution:**
```bash
cd agent
pip install -r requirements.txt --break-system-packages
```

If that doesn't work, use a virtual environment (see step 2 above).

---

### API Key Issues

**Problem:** `AuthenticationError: Invalid API key`

**Solution:**
1. Check that your API key starts with `sk-ant-api03-`
2. Verify no extra spaces in `config.yml`
3. Ensure the key is active in the [Anthropic console](https://console.anthropic.com/)

---

### Indexing Fails

**Problem:** Indexing crashes or hangs

**Solutions:**

1. **Large files:** Reduce `max_tokens_per_file` in `config.yml`
2. **Too many files:** Add more patterns to `ignore_patterns`
3. **Memory issues:** Close other applications or increase swap space
4. **Parse errors:** Check the terminal output for which file failed

To skip problematic files, add them to `ignore_patterns`:
```yaml
ignore_patterns:
  - "node_modules"
  - "path/to/problematic/file.js"
```

---

### Queries Return Poor Results

**Problem:** Agent doesn't find relevant code

**Solutions:**

1. **Reindex:** `python indexer.py --force`
2. **Check file is indexed:** Look in `agent_data/file_index.json`
3. **Be more specific:** Use actual function/variable names
4. **Check ignore patterns:** Make sure important files aren't ignored

---

### "No module named 'esprima'" or Similar

**Problem:** Missing a specific dependency

**Solution:**
```bash
pip install esprima --break-system-packages
# Or whatever package is missing
```

---

### GitHub Action Not Running

**Problem:** Auto-indexing workflow doesn't trigger

**Solutions:**

1. **Check secrets:** Ensure `ANTHROPIC_API_KEY` is set in repo secrets
2. **Check file paths:** Workflow triggers on `**.js`, `**.jsx`, etc.
3. **Manual trigger:** Go to Actions tab → Update Code Index → Run workflow
4. **Check logs:** Click on a workflow run to see error messages

---

### Permission Errors

**Problem:** `PermissionError: [Errno 13] Permission denied`

**Solutions:**

1. **Check file permissions:**
   ```bash
   chmod +x agent/cli.py
   chmod +x agent/indexer.py
   ```

2. **Run with proper permissions:**
   ```bash
   sudo pip install -r requirements.txt  # Not recommended
   # Or use a virtual environment instead
   ```

---

### ChromaDB Errors

**Problem:** `sqlite3.OperationalError: database is locked`

**Solution:**
1. Make sure no other process is running the indexer
2. Delete `agent_data/embeddings/` and reindex
3. Restart your computer (rare but sometimes needed)

---

### Rate Limiting

**Problem:** `RateLimitError: Too many requests`

**Solution:**
1. Wait a few minutes before trying again
2. Reduce `max_files_per_query` in config.yml
3. If indexing, it will retry automatically

## Advanced Configuration

### Custom Embedding Model

The default setup uses a simple hash-based embedding (for demo purposes). For production, integrate a real embedding model:

**Option 1: OpenAI Embeddings**
```python
# In indexer.py, replace get_embeddings() method
import openai

def get_embeddings(self, texts: List[str]) -> List[List[float]]:
    response = openai.embeddings.create(
        model="text-embedding-3-small",
        input=texts
    )
    return [item.embedding for item in response.data]
```

**Option 2: Local Model (Free)**
```bash
pip install sentence-transformers --break-system-packages
```

```python
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('all-MiniLM-L6-v2')

def get_embeddings(self, texts: List[str]) -> List[List[float]]:
    return model.encode(texts).tolist()
```

### Increasing Context Size

To include more files in queries, edit `config.yml`:

```yaml
max_files_per_query: 20  # Increase from default 15
max_tokens_per_file: 3000  # Increase from default 2000
```

**Note:** Higher values = more API tokens = higher cost per query.

### TypeScript Support

The agent already supports TypeScript (`.ts`, `.tsx`). The parser handles most TS syntax. For advanced type analysis, consider adding:

```bash
pip install typed-ast --break-system-packages
```

## Uninstalling

To remove the agent:

```bash
# Remove agent files
rm -rf agent/
rm -rf agent_data/
rm -rf .github/workflows/update-index.yml

# Remove Python packages (if in venv)
deactivate
rm -rf venv/
```

## Security Notes

1. **Never commit your API key** to version control
2. Keep `agent_data/` in `.gitignore` (it can be large)
3. For private repos, consider self-hosting the vector DB
4. The agent reads your entire codebase - ensure you trust the Anthropic API

### Recommended .gitignore entries:

```gitignore
# Code Agent
agent_data/
agent/config.yml
agent/venv/
agent/__pycache__/
```

### Recommended config template:

Create `agent/config.example.yml` (safe to commit):
```yaml
anthropic_api_key: "your-api-key-here"
repo_path: ".."
# ... rest of config
```

Then copy it for local use:
```bash
cp agent/config.example.yml agent/config.yml
# Edit config.yml with your real API key
```
