🎯 QUICK START (5 minutes):

1. Copy 'agent/' folder to your repo root
2. Install: pip install -r requirements.txt --break-system-packages
3. Configure: Edit agent/config.yml with your API key
4. Index: python indexer.py
5. Query: python cli.py
